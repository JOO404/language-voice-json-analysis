# 한국어 인터뷰·음성·JSON 분석 코드

인터뷰 전사, 발화 검수, 텍스트 감정·의도 분석, 음성 특징 분석에 사용한 최종 코드입니다.

- **코드와 분석 방법:** [영어 README](README.md)
- **실행 순서와 입력 형식:** [실행 안내](docs/RUN_GUIDE_EN.txt)
- **GitHub가 처음이라면:** [처음 사용하는 방법](docs/FIRST_GITHUB_KO.md)

## 무엇이 들어 있나요?

| 폴더 | 내용 |
| --- | --- |
| `code` | 전사, JSON 처리, 검수, 언어·음성 분석 코드 |
| `config` | 분석 설정, 모델 정보, BAR 기준값 |
| `requirements` | 분석에 사용한 패키지 버전 |
| `tests` | 분석 규칙과 입력 검증 테스트 |
| `example` | 가상 JSON과 시험용 신호 생성 코드 |
| `docs` | 실행 안내 |

원본 인터뷰 영상·음성, 실제 전사문, 참가자 명단과 개별 결과는 포함하지 않습니다.
시험용 오디오는 프로그램으로 만드는 단순 신호이며 사람이 말하는 녹음이 아닙니다.
실제 분석에는 별도로 보관한 자료와 모델 파일이 필요합니다.

## 간단한 확인

Python이 설치된 환경에서 저장소 폴더를 열고 실행합니다.

```console
python -m unittest discover -s tests -v
```

librosa를 사용하는 음성 분석은 실행 안내의 분석 환경을 먼저 설치한 뒤 진행합니다.
파일 검수 도구는 Windows 터미널에서 작동합니다.
