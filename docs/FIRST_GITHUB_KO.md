# GitHub 처음 사용하기

이 저장소는 분석 코드를 보관하고 사수님과 공유할 수 있는 온라인 폴더입니다.
첫 화면의 README가 설명서이고, `code`를 누르면 프로그램 파일을 볼 수 있습니다.

## 사수님께 전달하기

저장소 주소를 복사해 전달하면 됩니다. 비공개 저장소는 권한이 있는 계정만 볼 수 있습니다.
사수님에게 접근 권한이 필요하면 GitHub 사용자 이름을 확인한 뒤 저장소의
**Settings → Collaborators → Add people**에서 초대합니다.
공유할 사람을 정하지 않은 상태에서 협업자를 자동으로 추가하지는 않습니다.

## 내려받기

초록색 **Code → Download ZIP**을 누르면 파일을 내려받을 수 있습니다.
압축을 푼 뒤 `README.md`와 `docs/RUN_GUIDE_EN.txt`를 읽으면 됩니다.

## 수정 사항 저장하기

현재 온라인 파일은 마지막으로 업로드한 버전입니다. 내 컴퓨터에서 수정한 내용은
자동으로 GitHub에 반영되지 않습니다. 다음에 수정을 마치면 이 대화에서
“수정한 코드를 GitHub에 반영해줘”라고 요청하면 됩니다.

원본 음성·전사·참가자 표는 코드 저장소와 별도로 보관하세요. `.gitignore`에는
그런 자료, 모델 파일, 비밀번호 설정 등이 업로드되지 않도록 규칙을 넣어 두었습니다.

공식 안내: https://docs.github.com/en/repositories/creating-and-managing-repositories/quickstart-for-repositories
